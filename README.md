# 🎓 Blender Practice Repository

Этот репозиторий используется для обучения 3D-моделированию в Blender.

Занятия делятся на два типа:

---

## 🟢 Friday_Simple (Пятница — 1 час)

Лёгкие и быстрые проекты.
Цель: изучение базовых инструментов Blender.

📌 Примеры:
- моделирование простых объектов
- работа с материалами
- базовое освещение
- простые сцены

📂 Папка: `Friday_Simple/`

---

## 🔵 Sunday_Mega (Воскресенье — 3–4 часа)

Большие и комплексные проекты.

Цель: развитие навыков и создание полноценной сцены.

📌 Примеры:
- дома и архитектура
- окружение (лес, город)
- сцены с несколькими объектами
- работа с деталями и композицией

📂 Папка: `Sunday_Mega/`

---
